# Antwerpen caféstad

De metrokaart-poster "Antwerpen caféstad" (12 lijnen, 138 cafés) op de echte stad gelegd.

- `docs/index.html` – de kaart (wordt gepubliceerd via GitHub Pages)
- `data/cafes.json` – cafés, adressen, beschrijvingen, lijnen
- `scripts/` – bouwscripts; `fetch_osm.py` haalt echte OpenStreetMap-data op
- Actie **OSM-data verversen** (tabblad Actions) draait `fetch_osm.py` en commit de data

Pages aanzetten: Settings → Pages → Branch `main`, map `/docs`.
